Native APIs, passed through.

Wye is a small, stateless gateway between coding agents (Claude Code, Codex) or your own apps and the model providers. Requests go out as clients sent them; the only change is the model name, when an alias or a provider's own ids call for it. Which account a request uses, who may use which model, failover, upgrades, and prices sit in one TOML file you keep in Git, and every request leaves a record of its tokens and cost.

What it records

Each request becomes one JSON line, and with telemetry turned on, an OTLP log record, a span, and metrics. wye report reads the log without a backend. Costs are exact decimal strings computed in integers; a model with no price is recorded as unknown, never as $0.

One file, kept in Git

A route with two accounts, failover, and a price table. Secrets come from environment variables or files, never from the config, and an unknown field stops the gateway at startup.
