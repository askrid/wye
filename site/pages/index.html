Run your agents like infrastructure.█

Wye is a small, stateless gateway between your coding agents (Claude Code, Codex) or your apps and the model providers. Keys, models, failover, limits, and cost live in one TOML file in Git. Requests go out as clients sent them; the only change is a model name your config maps. Every request leaves a record of its tokens and cost.

# config
