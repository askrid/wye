Wye
Guide Configuration GitHub

Native APIs, passed through.

Wye is a small, stateless gateway between coding agents (Claude Code, Codex) or your own apps and the model providers. Requests go out as clients sent them; the only change is the model name, when an alias or a provider's own ids call for it. Which account a request uses, who may use which model, failover, upgrades, and prices sit in one TOML file you keep in Git, and every request leaves a record of its tokens and cost.
